This is a project I made while I was a TA for an introductory CS class at CMU (15-112). It was made as an optional "lecture" before the students were about to start on making their own term projects and I used it to
discuss small aspects of project design such as different files for different components, leaving
comments, and specific components that I knew students were interested in from a prior poll.

Warning: There are some minor bugs that I am aware of such as being able to phase through blocks
when the speed is very high or ducks completely not spawning when spawn rate is <4. There are definitely
also bugs that I am unaware of.
